# FileSave-Webapp
### A Webapp UI for a locally hosted File Server
*Developed by Chantal Westenberg and Jannes Schophuis*
 - -- 
This Project was developed in the university class "Webanwendungen" at the Hochschule Osnabrück.<br>

The aim of the software is to provide access to the FileSave Backend

### Login information
The Software uses Keycloak for authentication. To Access the 
integrated UI, use one of the following logins:
*Depends on the FileSave Backend. Default is:*
| User    | Password   |
|---------|------------|
| chantal | chantalSWA |
| jannes  | jannesSWA  |
| admin   | adminSWA   |

At the moment there is no Endpoint to dynamically add or change Users.

 - --

This Project uses the Ionic Framework with Angular.
